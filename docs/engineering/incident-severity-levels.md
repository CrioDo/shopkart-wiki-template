# Incident severity levels

Last reviewed: 3 Sep 2026.

| Level | Meaning | Example |
|---|---|---|
| SEV1 | customers can't order at all | checkout down everywhere |
| SEV2 | a major flow is degraded | payment gateway outage with the backup working |
| SEV3 | a minor flow is degraded | search stale for a day |

SEV1 and SEV2 need a written incident review within 5 working days.
