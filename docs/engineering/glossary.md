# Glossary

Last reviewed: 20 Jan 2026.

- **COD**: cash on delivery.
- **PIN code**: India's postal code; serviceability is checked per PIN code.
- **IST**: India Standard Time, UTC+5:30.
- **Plus**: ShopKart's paid membership.
- **Refund voucher**: a voucher issued instead of cash when a promotional voucher can't be reinstated.
