# Returns for marketplace sellers

Owner: Catalog. Last reviewed: 10 Sep 2026.

Marketplace sellers accept returns under the same windows as [Returns and refunds](returns-and-refunds.md).
Returned items go to the seller's warehouse, not ours, so the refund starts when the seller confirms the item
arrived, or after 7 days if the seller doesn't respond. Sellers with a return-dispute rate above 5% are reviewed
monthly by Catalog.
